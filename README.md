 AI Content Assistant

An AI-powered content generation assistant that helps users generate different types of content using real AI APIs.

 Features

- AI-powered content generation
- Multiple content types
- Tone selector
- Word count control
- Prompt history using localStorage
- Copy generated content
- Dark / Light mode
- Responsive UI
- Backend API integration
- Error handling

 Content Types

- Email
- LinkedIn Post
- Caption
- Blog Ideas

 Technologies Used

# Frontend
- HTML
- CSS
- JavaScript

# Backend
- Node.js
- Express.js

 AI Integration
- OpenRouter API

 Setup Instructions

 Clone Repository

```bash
git clone YOUR_GITHUB_REPO_LINK
```

 Install Backend Dependencies

```bash
cd backend
npm install
```

 Create Environment Variables

Create `.env`

```env
OPENROUTER_API_KEY=your_api_key
PORT=5000
```

 Start Backend

```bash
node server.js
```

 Run Frontend

Open `index.html` using Live Server.
